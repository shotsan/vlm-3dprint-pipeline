Autonomous Physical AI • Zero-Cloud LAN Mode

Deterministic VLM-to-3D-Print Pipeline

An industrial manufacturing pipeline that transforms 2D technical sketches, diagrams, and photos into verified, 100% watertight 2-manifold B-Rep solids, slices them headlessly via OrcaSlicer, and dispatches them over local LAN directly to Bambu Lab 3D printers.

⚡ Quickstart Guide 🖥️ Launch Web Studio

Introduction

Standard generative 3D approaches (SDFs, NeRFs, triplane diffusion, and raw free-form LLM code generation) produce meshes full of non-manifold edges, inverted normals, floating artifacts, and unprintable thin walls. A 3D printer mainboard cannot slice visual illusions—it requires mathematically exact boundary representation (B-Rep) solids that strictly adhere to FDM additive manufacturing constraints.

VLM 3D Print Pipeline bridges high-level visual understanding with rigorous mechanical engineering. Instead of asking Vision-Language Models to hallucinate raw geometry, it constrains the VLM to act as a CAD Slot-Filler that selects pre-validated engineering building blocks from an exhaustive catalog (fasteners, bearings, motor mounts, spur gears, brackets, and aerodynamic airframes) parameterized by real-world millimeters.

Core Philosophy & Invariants

🛡️
Deterministic AST Slot-Filling

VLMs never write unstructured code. They emit strictly typed AssemblyPlan abstract syntax trees validated against physical Pydantic schemas.

📐
Exact Mathematical Solids

Powered by OpenCASCADE, build123d, and bd_warehouse to produce true STEP solids with calibrated press-fit and fastener clearances.

⚙️
Real Headless Slicing

Direct OrcaSlicer CLI integration generating legitimate .gcode.3mf archives with tree supports, gyroid infill, and plate metadata.

🔒
Zero-Cloud Bambu LAN Mode

Bypasses proprietary cloud dependencies entirely. Communicates with Bambu Lab P1S/X1/A1 printers via local FTPS (port 990) and MQTT TLS (port 8883).

Quickstart Installation

Install the pipeline and its solid modeling dependencies in a Python 3.10+ environment:

# 1. Clone repository
git clone https://github.com/shotsan/vlm-3dprint-pipeline.git
cd vlm-3dprint-pipeline

# 2. Install Python package in editable mode
pip install -e .

# 3. Setup OrcaSlicer headless CLI engine (one-click installer)
vlm-print setup-slicer
💡
Automatic Slicer Setup: Running vlm-print setup-slicer downloads the official headless Linux AppImage to ~/.local/bin/orca-slicer and configures built-in Bambu Lab P1S profiles automatically.

Launch the Interactive Web Studio

Start the local real-time 3D inspection studio with side-by-side conversational chat:

vlm-print studio --port 8000

Navigate your browser to http://127.0.0.1:8000.

5-Gate Pipeline Architecture

1
Multimodal Slot-Filling Visual input is parsed by Gemini 2.0 Flash / Claude 3.5 Sonnet or the local Parametric NLP engine into an AssemblyPlan AST.
2
Physical Boundary Contract Gatekeeper Pydantic enforces Bambu P1S bed bounds (256x256x256mm), minimum wall thickness (≥ 1.2mm for 0.4mm nozzle), and standard fits.
3
OpenCASCADE B-Rep Solid Compilation build123d and bd_warehouse compile exact solids, export STEP geometries, and tessellate 2-manifold STL meshes.
4
DFM Printability Audit & Real Headless Slicing Verifies watertight manifoldness and overhang angles. OrcaSlicer headlessly slices toolpaths, generating true G-code and time/filament predictions.
5
Zero-Cloud Local LAN Dispatch Uploads the .gcode.3mf archive over FTPS (port 990) and initiates printing via local MQTT (port 8883) with real-time telemetry streaming.

OrcaSlicer & Bambu Studio Headless Engine

Rather than relying on simulated estimates or un-sliceable STLs, the pipeline executes real toolpath generation via OrcaSlicer CLI. The engine loads calibrated JSON configuration profiles: 

# Automatic headless slicing executed by the pipeline
orca-slicer \
  --load-settings "resources/profiles/machine/Bambu Lab P1S 0.4 nozzle.json;resources/profiles/process/0.20mm Standard @BBL X1C.json" \
  --load-filaments "resources/profiles/filament/Bambu PLA Basic @BBL X1C.json" \
  --slice 0 \
  --outputdir ./sliced/ \
  --export-3mf model.gcode.3mf \
  ./cad/model.stl

The generated .gcode.3mf is an uncompressed ZIP containing Metadata/slice_info.config. The pipeline extracts exact execution predictions directly from the G-code toolpath stream: 


<config>
  <plate>
    <metadata key="prediction" value="2712" />  <!-- 45.2 minutes -->
    <filament used_m="2.47" used_g="7.4" />   <!-- 7.4 grams PLA -->
  </plate>
</config>

Zero-Cloud Bambu Lab P1S LAN Communication

Bambu Lab printers feature an onboard "LAN Only Mode" that enables local control without external internet access or third-party cloud brokers: 

# Set environment variables for local Bambu P1S / X1C / A1
export BAMBU_IP="192.168.1.150"
export BAMBU_SERIAL="01P00A000000000"
export BAMBU_ACCESS_CODE="12345678"  # 8-digit passcode from printer LCD screen

# Query live status over LAN MQTT TLS (port 8883)
vlm-print status
⚠️
Security & Privacy: Operating in LAN Mode prevents printer telemetry, print files, and camera streams from being uploaded to external cloud servers.

Interactive Multimodal Web Studio

The Web Studio provides a real-time, right-hand-optimized workstation designed for iterative mechanical design:

  • Left 3D Viewport: Interactive Three.js WebGL solid visualizer with orbit controls, 256x256mm build plate grid, wireframe toggle, and a custom GLSL Overhang Heatmap Shader highlighting faces > 45° in real time.
  • Right Conversational Pane: Modern chat interface with multiline input capsule, drag-and-drop sketch/image attachment, prompt pill suggestions, and live physical manifold badges.
  • Engine Settings Modal: Switch on the fly between the Offline Parametric CAD Engine (zero keys needed), Google Gemini 2.0 Flash, Anthropic Claude 3.5 Sonnet, or OpenAI GPT-4o.

CLI Reference

Command Description
vlm-print studio [--port 8000] Launches the local interactive Web Studio with Three.js solid inspection and multimodal iteration chat.
vlm-print setup-slicer Downloads and configures the official OrcaSlicer headless AppImage in ~/.local/bin/.
vlm-print run <image> [--guidance "..."] Executes the full 5-gate pipeline from visual input to sliced 3MF or automated LAN print.
vlm-print status Connects to Bambu P1S/X1/A1 over local MQTT TLS and streams live nozzle/bed temperatures and print status.
vlm-print audit <file.stl> Audits a mesh for watertight 2-manifold boundaries and overhang angles exceeding 45°.
vlm-print catalog Prints all 105+ building blocks, scalar parameter boundaries, and standard engineering definitions.
vlm-print serve Starts the Model Context Protocol (FastMCP) server over STDIO for AI coding agents.
